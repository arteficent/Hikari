特Why Hikari?

Built for people who'd rather own their library than rent it.

☁️

Bring your own cloud — or none

Metadata in DynamoDB or MongoDB; binaries in S3, Cloudflare R2, MinIO or Spaces. Mix and match, or self-host everything with one docker compose up.

📴

Offline-first

Synced files land in /sdcard/Hikari or %USERPROFILE%\Hikari, laid out like the server, so your favourite players and readers just see them.

🧩

One plugin contract

Each media type is a plugin implemented identically on server, Android and Windows. Add one and you get a new endpoint, tab, form and sync flow.

🏷️

Tags straight from the file

ID3, FLAC, MP4, EPUB OPF, CBZ covers — read on-device and pre-filled into the upload form. Edit them and Hikari rewrites the file's metadata before uploading.

♾️

Infinite library

Endless scrolling with prefetch, per-type sort options, instant local filter and server-side field filters for large libraries.

📦

Bulk download & delete

Select All, then download or delete in one go. Files already on the device are kept, not re-downloaded, and downloads are size-checked.

🔄

Local-state refresh

One tap reconciles the list with what's really on disk: files you deleted are dropped, files you copied in are adopted.

🔐

Secure by default

JWT with refresh tokens, a strict root › admin › user hierarchy, DPAPI-sealed tokens and no plaintext sign-in on Windows and short-lived presigned URLs for the bytes.

🎨

Actually pretty

Wisteria, Sakura, Golden Leaf and an animated Celestial sky — Material 3 on Android, a washi-paper WinUI 3 shell on Windows. Try them with the dots in the top bar.

問FAQ

  
Does Hikari stream my media?
No. The server handles sync only. Files are downloaded to the device and played or read by whatever app you already like, completely offline.

  
Do my files pass through the server?
No. The server hands out short-lived presigned URLs and the bytes go directly between your device and object storage. The API only ever sees metadata.

  
Can I run it without any cloud account?
Yes. The bundled Docker Compose stack runs MongoDB, MinIO and the server on your own machine, and MinIO can even sit on an SMB/NAS share. There's also an ARM image for running the API on an Android phone via Termux.

  
Will re-downloading overwrite files I already have?
No. Bulk download skips files that already exist on the device and adopts them instead, and every download is size-checked so a truncated file is never kept.

  
How do I add a new kind of content?
Implement the plugin interface once on the server (C#), once on Android (Kotlin) and once on Windows (C#), then register each. The new type appears in every picker with its own form, filters and sort options.

  
Is the Windows app signed?
Release builds are Authenticode-signed when a certificate is configured in CI; otherwise the exe is published with an -unsigned suffix and SmartScreen may warn on first launch. The app needs the Windows App Runtime installed.
